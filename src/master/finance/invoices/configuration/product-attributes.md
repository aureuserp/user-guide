# Product attributes

Attributes describe the variations of a product, such as size or color. Each option can add an extra price to the base price.

> **In simple words:** An attribute is a choice, like Size, with options, like Medium.

## Create an attribute

1. Go to `Invoices → Configurations → Attribute`.
2. Click **New Attribute**.

   <ImagePopup src="/images1/invoices/attribute_create.png" alt="Attributes list with the New Attribute button" />

### General

- **_Name:_** Enter the attribute label, such as Size or Fabric.
- **_Type:_** Choose **Radio**, **Select** or **Color**.

### Options

The option fields depend on the type you chose.

- **_Name:_** Enter the option name, such as Medium or Blue.
- **_Extra Price:_** Enter the amount added to the base product price.

<ImagePopup src="/images1/invoices/attribute_create_1.png" alt="Attribute form with general and options sections" />

3. Save the attribute.

::: tip
Add the attribute to a product to generate its variants. See [Manage products](../products/manage-products.md).
:::
