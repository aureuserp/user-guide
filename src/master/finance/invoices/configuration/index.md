# Configuration

Configuration holds the shared setup behind every invoice and bill. Set it up once before you create documents. Taxes, payment terms and bank accounts feed directly into your customer and vendor flows.

> **In simple words:** This is where you prepare the building blocks that invoices and bills reuse.

## In this group

- [Invoice settings](./settings.md): turn on units of measure for products.
- [Bank accounts](./bank-accounts.md): record the accounts used for payments.
- [Payment terms](./payment-terms.md): define due dates, early discounts and due terms.
- [Incoterms](./incoterms.md): define shipping responsibility codes.
- [Taxes](./taxes.md): create tax groups, then individual taxes.
- [Product categories](./product-categories.md): group products in a tree.
- [Product attributes](./product-attributes.md): define options such as size and color.
