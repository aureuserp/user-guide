# Product categories

Categories group your products and services into a tree. They make products easier to find, filter and report on.

> **In simple words:** A category is a folder for similar products.

## Create a category

1. Go to `Invoices → Configurations → Categories`.
2. Click **New Categories**.

   <ImagePopup src="/images1/invoices/category.png" alt="Categories list with the New Categories button" />

3. Fill in the fields.

   - **_Name:_** Enter the category name, such as Women's Clothing.
   - **_Parent:_** Select the parent category, such as All > Clothing.

   <ImagePopup src="/images1/invoices/category_create_1.png" alt="Category form with name and parent" />

4. Save the category.

::: info
Products use categories in both sales and purchases, which helps tracking and reports.
:::
