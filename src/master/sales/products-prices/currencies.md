# Currencies

The currency list holds every currency you can use on quotations, orders and price lists. Only active currencies can be chosen. The base currency of your company is set elsewhere.

> **In simple words:** This list shows which currencies are switched on.

## Overview

Go to `Sales → Configurations → Currencies`. The list has these tabs:

- **All:** Every currency.
- **Active:** Currencies you can use.
- **Inactive:** Currencies that are switched off.

The list shows **Currency Name**, **Symbol**, **Full Name**, **ISO Code**, **Decimal Places**, **Rounding** and **Status**. Use **Group by** for **Name**, **Status** or **Decimal Places**. Click **New Currency** to add one.

<ImagePopup src="/images1/sales/cfg_currencies.png" alt="Sales → Configurations → Currencies list with the All, Active and Inactive tabs" />

::: tip
Switch a currency to active before you pick it on a price list or a quotation.
:::

## Base currency

Your company has one base currency. See [Currency](../../general-settings/companies/currency.md).
